# cas-makeover

This repository now contains a static website inspired by the reference page structure,
with only these top menu items:

- Home
- About
- Services
- Contact

## Files

- index.html
- styles.css
- script.js
- .nojekyll

## Run locally

Open `index.html` directly in your browser, or use any static server.

## Host from this repo (GitHub Pages)

1. Push this repository to GitHub.
2. In repository settings, open **Pages**.
3. Under **Build and deployment**, choose:
	- Source: `Deploy from a branch`
	- Branch: `main` (or your default branch)
	- Folder: `/ (root)`
4. Save settings and wait for deployment.

Your site will be served from GitHub Pages using only files in this repository.
